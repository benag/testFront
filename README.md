# ORANZON Homepage

A modern creative agency homepage built with React and Tailwind CSS.

## Setup Instructions

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Project Structure

- Modern React application with Tailwind CSS
- Responsive design matching the provided design mockup
- Orange gradient theme with black background
- Sections: Hero, Services, Selected Work, Footer CTA
